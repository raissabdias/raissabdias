### Projetos em Destaque

> #### **DarkMode** | [Acesse o Portal](https://www.darkmode.com.br/) • [Repositório](https://github.com/raissabdias/dark-mode)
> **Portal de notícias e entretenimento com gestão dinâmica de conteúdo.**
> - **Backend:** Laravel 11 + **FilamentPHP** para um painel administrativo robusto (CRUDs, SEO e Ads).
> - **Frontend:** Interface SPA construída com **Vue.js 3** e TailwindCSS.
> - **Destaque:** Implementação de editor Tiptap customizado e sistema de comentários com moderação.



> #### **My Plot** | [Acesse a Estante](https://my-plot-wxi1.onrender.com) • [Repositório](https://github.com/raissabdias/my-plot)
> **Estante virtual para organização de leituras e acompanhamento de metas.**
> - **Backend:** API REST em Laravel 11 utilizando **Service Pattern** para desacoplamento de lógica.
> - **Frontend:** SPA reativa com **Vue 3**, Composition API e componentes **PrimeVue**.
> - **Integração:** Consumo da **API Google Books** e armazenamento de mídia no Cloudinary via Docker.
> - **Destaque:** Avaliações e resenha de livros, definição de metas anuais.
